INSTALL ON YOUR XBOX

Two folders. Clear destinations.

Content → Hdd1:/Content/Games, DLC, XBLA, and content title updates. Keep the GoD header and its .data folder together.
Cache → Hdd1:/Cache/Only when included. Uppercase TU_* files go here, outside the Content folder.

Every latest bundle includes INSTALL-ON-XBOX.txt. In Aurora, scan the content path and enable the matching update. File checks do not confirm a launch on your console.

FROM BUNDLE TO CONSOLE

Install your latest bundle

  1. Download the latest game bundle.

    Extract it on your computer. Saved files in job history can be partial or older; use the main download for installation.

  2. Copy Content to Hdd1:/.

    Merge the folders. A GoD game lives under Content/0000000000000000/<TITLEID>/00007000/. Keep its header and matching .data folder beside each other.

  3. Copy Cache separately, if included.

    Uppercase TU_* files belong in Hdd1:/Cache/. Lowercase tu... updates stay inside the title's 000B0000 folder.

  4. Scan and test in Aurora.

    Scan your content path and enable the matching title update. If a game exits while applying an update, disable that update and test again.

A “passed” file check verifies the package, not playback on a physical Xbox. Each bundle includes the same instructions and its own check report.
